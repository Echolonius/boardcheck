# Security

Please report security problems privately through GitHub:
[report a vulnerability](https://github.com/Echolonius/boardcheck/security/advisories/new). Don't open a public issue.

Especially useful: listing text that makes Boardcheck itself misbehave (a crash or a hang on crafted input), a way
to make the MCP server read files or reach the network, or a reliable way to hide a known warning sign from a check.

Boardcheck runs on your own machine and keeps no data, so there is no server of ours to attack. Only the latest
release is supported.
